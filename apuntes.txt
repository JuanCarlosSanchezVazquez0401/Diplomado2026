Pull request - Es escencialmente una solicitud formal para añadir o retocar codigo en 
un repositorio Representa el mecanismo principal para la colaboracion, especialmente cuando
los desarroladores no tienen permisos de escritura directos en el repositorio

En el contexto de Git una PR es la forma en que un colaborador indica que ha completado un 
trabajao a una rama y desea que esos cambios se fusionen en la rama principal del proyecto

Code review - La revision de codigo es el proceso central que ocurre una vez que se ha 
abierto una PR 

Gestion de conflictos

Indicar la discrepancia: El editor de GitHub puede mostrar las dos posibilidades de codigo

rama de la PR

--------------ramas secundaria-----------------------

git branch - ver mis ramas
git branch [nombre] - crear nueva rama
git checkout [nombre] - cambiar a la rama que queramos, cuando esta seleccionada esta en verde
git push -u origin [nombre rama]/// git push --set-upstream origin [nombre rama]- para subir cambios por primera vez a una 
					rama secundaria
git branch -m [nombre actual] [nuevo nombre] - renombramos ramas
--------------------------------------------------------------------------------------------------------
IMPORTANTE - CUANDO SE TRABAJA CON RAMAS Y HACEMOS PUSH SIEMPRE INDICAR AL FINAL DEL PUSH LA RAMA
--------------------------------------------------------------------------------------------------------

git push origin :[nombre] - borra la rama remota de bugs - [:] indica rama remota
git branch -d [nombre] - revisa que este integradas las ramas con el repositorio (tu rama actual)
git branch -D [nombre] - borra la rama indicada directamente, IMPORTANTE, no puedes borrar tu rama actual, 
			tienes que cambiar a otra primero y luego borrarla

------------------------------------Unir ramas-------------------------------------
	
git merge [rama cambios] [rama a implementar] - unir cambios de ambas ramas
Si los cambios tienen conflictos se tiene que resolver a mano esos conflictos y luego hacer el merge o bien hacer un revert
VS code es una herramienta muy util para revisar los cambios
